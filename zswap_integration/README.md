# AOCL-LZ4 → zswap integration

This tree integrates the kernel-safe **AOCL-LZ4** codec into Linux **zswap** as a
selectable crypto compressor named `aocl-lz4`, and provides a benchmark harness
to compare it against the kernel's stock `lz4` on a page-at-a-time workload.

The compress side uses the default LZ4 hash, so the compressed byte stream is
**bit-identical to stock LZ4**: pages written by `lz4` decode with `aocl-lz4`
and vice-versa. The optimization work is on the **decode** path (kernel-safe,
scalar software-pipelined prefetch by default; an AVX2 decoder is an opt-in
build).

## 1. Directory layout

The **product** lives at the top level; everything used only for benchmarking
is under `harness/`.

| Path | Role |
|------|------|
| `module/` | The loadable kernel module (`aocl_lz4.ko`) that registers the `aocl-lz4` crypto `scomp` compressor. This is the deployable product. |
| `aocl-kernel/` | Kernel-safe AOCL-LZ4 codec the module links against (adapted `lz4.c`, headers, `glue.c`). See `aocl-kernel/PROVENANCE.txt`. |
| `harness/kernel-lz4-baseline/` | Faithful copy of the kernel's in-tree LZ4 (v6.8 `lib/lz4`), used as the A/B baseline. See its `PROVENANCE.txt`. |
| `harness/bench/` | Benchmark drivers: `zswap_bench.c` (userspace micro-benchmark) and `zswap_kernel_workload.c` (real-kernel swap workload). |
| `harness/scripts/` | `build_impl.sh` (build a userspace driver against one compressor), `gen_corpus.py` (regenerate the synthetic corpus), `run_real_zswap_bench.py` (real in-kernel A/B runner). |
| `harness/kcompat/` | Minimal shim headers that let the kernel-flavored codec sources compile in the userspace harness. |
| `harness/corpus/` | Synthetic 4 KiB-page corpus for the userspace harness (regenerated by `gen_corpus.py`; not tracked). |

## 2. The zswap integration (`module/`)

zswap stores/loads one page (4 KiB) at a time through the crypto `scomp` API.
`aocl_lz4_zswap.c` registers a `scomp` provider whose:

- **compress** callback calls the AOCL 5-arg `LZ4_compress_default(src, dst, slen, dcap, wrkmem)`;
- **decompress** callback calls `LZ4_decompress_safe(...)`.

By default the decoder is **kernel-safe scalar** (no SIMD, so no FPU state to
save) and needs no `kernel_fpu` bracketing. When built with `AOCL_LZ4_AVX=1`,
decode routes to AOCL's AVX2 decoder and each per-page decode is wrapped in
`kernel_fpu_begin()/kernel_fpu_end()`. Build/deploy details are in
`module/README.md`.

## 3. Benchmark harness

Two complementary harnesses are provided.

### 3a. Userspace micro-benchmark (no root)

Compiles the exact codec sources with kernel-safe flags and measures
compress/decompress/round-trip throughput per corpus class and simulated
pressure level:

```sh
cd harness
python3 scripts/gen_corpus.py                    # regenerate corpus/*.bin
bash scripts/build_impl.sh baseline build/baseline.bin
bash scripts/build_impl.sh aocl     build/aocl.bin
./build/aocl.bin --selftest                      # correctness round-trip
./build/aocl.bin                                 # CSV matrix: class,pressure,op,mbps
```

`build_impl.sh` accepts `baseline`, `aocl` (scalar decode, matches the module
default), and `aocl_avx` (AVX2 decoder). The compressor translation units are
always compiled with kernel-safe flags (freestanding, no SIMD/autovectorization)
so the comparison reflects what actually runs in-kernel; only the harness driver
uses `-march=native`.

### 3b. Real in-kernel A/B (requires root)

`run_real_zswap_bench.py` loads `aocl_lz4.ko`, then for each round compares
`compressor=lz4` vs `compressor=aocl-lz4` under a real swap path:

```sh
sudo python3 harness/scripts/run_real_zswap_bench.py --rounds 5 --decode-backend scalar
```

Protocol per run: start the workload unconstrained, let it fill memory
(`fill_done`), move it into a memory-limited cgroup, trigger `MADV_PAGEOUT` so
pages are compressed into zswap (`pageout_done`), then scan all pages back in
(swap-in / decompress, `scan_done`). The runner samples zswap debugfs counters
and `/proc/vmstat` before/after each phase and writes
`harness/results/real_zswap/{raw.jsonl,summary.csv,env.json}`.

## 4. Test methodology

- **Page granularity.** All measurements are per 4 KiB page, matching zswap.
- **Kernel-safe compilation.** Codec sources are built freestanding, without
  SIMD/FPU or autovectorization (except the explicit AVX decoder variant), so
  userspace results correspond to in-kernel behavior.
- **Ratio neutrality.** Compress output is bit-identical to stock LZ4; decode
  optimizations are hint-only and byte-exact. Correctness is enforced by the
  `--selftest` round-trip and, in-kernel, by cross-decode compatibility.
- **A/B fairness.** Baseline (`lz4`) and candidate (`aocl-lz4`) run the same
  corpus, iteration counts, and (for the real test) identical zswap parameters
  and cgroup limits; the real runner alternates compressors within each round
  and reports paired deltas.
- **Determinism.** The userspace corpus is seeded and reproducible; the
  micro-benchmark reports the median of repeated sub-trials.
